# 须佐能乎 — 完整功能规格

> 本文档基于 narutomod 源码（1.12.2 Forge）提取，覆盖从召唤、形态升级、持续消耗、战斗 AI 到取消清理的全流程。

---

## 1. 召唤条件

### 1.1 所需眼睛

检测玩家**头盔槽**（`inventory.armorInventory[3]`）或**虚拟瞳术槽**中的物品是否为写轮眼族系（MangekyoSharingan 家族），通过物品标签/类继承判定。

### 1.2 前置判定

| 条件 | 说明 |
|------|------|
| 物品存在 NBT 且 `sharingan_blinded` 不为 `true` | 未被致盲 |
| `susanoo_activated` 为 `false` | 当前未召唤须佐 |
| BATTLEXP >= 2000 | 即 `BXP_REQUIRED_L0` |
| 查克拉 >= 500 | 召唤消耗 `BASE_CHAKRA_USAGE`，直接从玩家查克拉扣除 |

### 1.3 召唤流程

1. 设置 `susanoo_activated = true`
2. 设置 `susanoo_cd = world_tick + 2400`
3. 生成 `EntitySusanooSkeleton.EntityCustom(player, false)`（初始半身骨架形态）
4. 记录 `summonedSusanooID = entity.getEntityId()`

## 2. 按键与输入

| 操作 | 说明 |
|------|------|
| 召唤须佐 | 原版按键（通过 ItemSharingan 的 onArmorTick 检测按键状态后调用 `ProcedureSusanoo.execute()` |
| 升级须佐 | 原版升级键（骑乘状态下调用 `ProcedureSusanoo.upgrade()` |
| 下马 | Shift 下马，下马后须佐获得 AI（自主战斗） |
| 再按召唤键取消 | 此时 `susanoo_activated` 为 `true`，`execute()` 走取消分支 |

## 3. 形态与升级

> 升级机制评估中——需要确定是**重换实体**还是**修改实体渲染**，待子代理评估后决定。

### 3.1 等级总表

| 等级 | BATTLEXP | 实体类 | 形态名称 |
|------|----------|--------|----------|
| L0 | 2000 | `EntitySusanooSkeleton.EntityCustom(player, false)` | 骨架 · 半身 |
| L1 | 5000 | `EntitySusanooSkeleton.EntityCustom(player, true)` | 骨架 · 完整上半身 |
| L2 | 10000 | `EntitySusanooClothed.EntityCustom(player, false)` | 着衣 · 无腿 |
| L3 | 20000 | `EntitySusanooClothed.EntityCustom(player, true)` | 着衣 · 有腿 |
| L4 | 40000 | `EntitySusanooWinged.EntityCustom(player)` | 完全体（有翼） |

### 3.2 升级机制（原版参考）

由 `ProcedureSusanoo.upgrade(player)` 处理：

1. 检测玩家当前骑乘的实体是否为 `EntitySusanooBase`
2. 根据当前实体的类型和状态 + BATTLEXP 判定可升级目标
3. 每次升级消耗 **500 查克拉**
4. 升级路径不可跨级，必须按 L0→L1→L2→L3→L4 逐级晋升

#### 具体升级判定

```
L0 (skeleton half-body, isFullBody==false)
  → BXP >= 5000, 消耗500查克拉 → L1 (skeleton full-body, isFullBody==true)

L1 (skeleton full-body, isFullBody==true)
  → BXP >= 10000, 消耗500查克拉 → L2 (clothed without legs, hasLegs==false)

L2 (clothed without legs, hasLegs==false)
  → BXP >= 20000, 消耗500查克拉 → L3 (clothed with legs, hasLegs==true)

L3 (clothed with legs, hasLegs==true)
  → BXP >= 40000, 消耗500查克拉 → L4 (winged)
```

## 4. 持续消耗

### 4.1 基础消耗公式

每 **20 tick（1 秒）** 执行一次查克拉消耗：

```
消耗量 = chakraUsage × chakraUsageModifier
```

- 如果 `Chakra.pathway(owner).consume(amount)` 返回 `false`（查克拉不足），则 `setDead()` 立刻解除须佐

### 4.2 各形态基础消耗

| 形态 | chakraUsage | 每秒消耗（按 owner 算） |
|------|-------------|------------------------|
| L0 骨架半身 | 30 | 30 |
| L1 骨架完整 | 30 | 30 |
| L2 着衣无腿 | 60 | 60 |
| L3 着衣有腿 | 70 | 70 |
| L4 完全体 | 90 | 90 |

> 注：均按 owner 计算，`chakraUsageModifier = 1.0`。非原主场景已取消。

### 4.3 剑持消耗

着衣及以上形态持剑时 `chakraUsage += 15`。

### 4.4 创造模式豁免

创造模式下跳过所有查克拉消耗。

## 5. 状态与字段

所有状态存储在玩家的 `EntityData`（`NBTTagCompound`）中：

| 字段名 | 类型 | 作用 | 清理时机 |
|--------|------|------|----------|
| `susanoo_activated` | boolean | 标记须佐当前是否激活 | 取消、死亡、换维度、登出、断线 |
| `summonedSusanooID` | int | 当前须佐实体的 Entity ID | 取消、死亡、换维度、登出、断线 |
| `susanoo_cd` | double | 冷却结束时的 world_tick 值 | 取消时清除 |
| `susanoo_ticks` | double | 须佐存活 tick 计数器 | 取消时清除 |

| 参数 | 值 |
|------|-----|

- L2+ 每 20 tick 从玩家处复制攻击目标
- 目标死亡后清除
- 不对创造模式/旁观模式玩家攻击

## 9. 音效与粒子

### 9.1 音效

- 每 30 tick：`block.fire.ambient`（火焰环境音）
- 死亡：`item.shield.break`
- 八尺琼勾玉旋转：`narutomod:magatama_spin` 每 12 tick

### 9.2 火焰粒子

- 每 tick 生成 `(int)height` 个 `Particles.Types.FLAME` 粒子
- 位置环绕实体身体随机分布
- 颜色从瞳术获取，默认 `0x202C183D`

## 10. 取消与清理

### 10.1 取消流程

再按一次召唤键（`susanoo_activated == true` 时进入取消分支）：

```
cooldown (tick) = susanoo_ticks × 0.25
cooldown = cooldown × getCooldownModifier(player)
getCooldownModifier = 1.0 / (0.5 + 0.02 × √BATTLEXP)
```

### 10.2 惩罚

| 条件 | 效果 |
|------|------|
| 非创造模式 **且** 非轮回眼持有者 | 虚弱（WEAKNESS, amplifier 3, 持续 `(int)cooldown` tick） |
| 同上 | 反胃（NAUSEA, amplifier 2, 持续 `(int)cooldown` tick） |
| 总是 | 羽落（Feather Falling, amplifier 5, 持续 60 tick） |

创造模式 → 无惩罚。轮回眼持有者减少惩罚。

### 10.3 清理操作

1. 移除 `susanoo_activated` 标签
2. 移除 `susanoo_ticks` 标签
3. 移除 `summonedSusanooID` 标签
4. 通过 Entity ID 找到须佐实体，执行 `setDead()`

### 10.4 清理事件

| 触发条件 | 说明 |
|----------|------|
| 玩家主动取消 | 再按召唤键 |
| 查克拉耗尽 | `consumeChakra()` 中 `setDead()` |
| 须佐实体死亡 | 正常伤害处理 |
| 玩家死亡 | 清理标记 |
| 换维度 | 取消须佐 |
| 登出/断线 | 取消须佐 |
