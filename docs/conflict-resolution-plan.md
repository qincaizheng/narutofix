> 背景：当前 todo 为在玩家背包页面顶部或底部显示血脉、身体能量、灵魂能量、查克拉能量及其实时回复速度，并适配原版缩放。
> 项目为 Minecraft 1.12.2 Forge Java 8 mod；文档统一放 `docs/`；项目读取与验证走 IDEA MCP；本轮不跑编译/测试，仅做规划。
